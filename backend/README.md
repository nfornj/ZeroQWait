# FastCuts Backend

FastAPI backend for the FastCuts haircut service finder application.

## Development

This project uses PDM for dependency management.

### Setup

```bash
# Install PDM
pip install pdm

# Install dependencies
pdm install

# Run the application
pdm run start
```

### Available Commands

- `pdm run start`: Start the development server
- `pdm run test`: Run tests
- `pdm run lint`: Run linting checks

## API Documentation

When the server is running, you can access:

- API documentation at `/docs`
- Alternative API documentation at `/redoc`
