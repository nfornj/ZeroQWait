🚀 Quick Start Guide

System Overview

ZeroQwait is an AI-powered queue management system for barbershops. It allows customers to join queues online, check wait times, and receive services while enabling staff to manage appointments efficiently.

Website URL

Production: https://urban-trim-oshawa.zeroqwait.com
Test Environment: http://localhost:3000 (local)

Key Features to Test

  • Queue Management: Join queue, check position, wait time estimation
  • AI Chat: Talk to the shop's AI receptionist
  • Voice Support: Use voice commands to interact with AI
  • Service Selection: Browse and book services with pricing
  • Payment: Make payments for services online
  • Employee Dashboard: View queues and manage customers
  • Owner Portal: Analytics, revenue tracking, staff management

📋 Testing Scenarios

Scenario 1: Customer Queue Join & Payment

  1. Go to https://urban-trim-oshawa.zeroqwait.com
  2. Click "Join Queue" button
  3. Enter your name and select a service
  4. Receive a queue position (You are #XX in queue)
  5. Click "Pay for Service" button
  6. Use Stripe test card: 4242 4242 4242 4242
  7. Any future expiry date (e.g., 12/25)
  8. Any CVC (e.g., 123)
  9. Verify payment success notification

Scenario 2: Employee Dashboard Access

  1. Go to https://urban-trim-oshawa.zeroqwait.com/login
  2. Use employee credentials: test_bulk_emp_0_0_8410
  3. View active queue
  4. Click "Call Next Customer" to move to next queue item
  5. Verify queue updates in real-time
  6. Check employee shift status

Scenario 3: Owner Dashboard & Analytics

  1. Go to https://urban-trim-oshawa.zeroqwait.com/dashboard
  2. Login with owner credentials: donna_sanchez_421@zeroqwait.com
  3. View live queue status (#32 displayed)
  4. Check analytics and revenue metrics
  5. Review employee list and shifts
  6. Test AI Inbox (ask AI questions about business)

Scenario 4: AI Chat Interaction

  1. On the public page, look for "NOW CHATTING WITH" box
  2. Click the chat interface
  3. Type: "What services do you offer?"
  4. Verify AI responds with service list
  5. Type: "How long is the wait?"
  6. Verify AI provides real wait time
  7. Click microphone icon to test voice input (if available)

Scenario 5: Voice Mode Testing

  1. In top-right controls, click "VOICE" button
  2. Speak: "Join the queue for a haircut"
  3. Verify AI understands and responds with voice
  4. Ask: "What's the wait time?"
  5. Hear AI response with audio output
  6. Test switching between Voice and Chat modes
